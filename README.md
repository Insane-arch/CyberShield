A Java project for the Parallel and Distributed Computing course.

## Objective
Simulate attack propagation through a virtual computer network
and compare containment strategies using sequential, parallel,
and distributed execution.

## Planned Features
- Generate a virtual network of computers and connections.
- Simulate compromise, isolation, and protection of computers.
- Compare three containment strategies.
- Implement a sequential baseline.
- Implement parallel execution using Java multithreading.
- Distribute simulation trials using socket-connected workers.
- Visualize network states and experiment results.
- Measure execution time, speedup, and efficiency.

## Evaluation Approach
Use identical scenarios and random seeds across execution modes.
Check that results agree before comparing performance.
Measure simulation performance separately from interface rendering.

## Scope
All attack behaviour takes place inside a software simulation.
The project does not execute malware or attack real computers.
